# Graphics Studio (MF theme)

Web app renders each **renderable** frame from `spec.json` via `templates/render.js`. Types `footage`, `screen`, and `repeat` are storyboard-only placeholders in the UI.

When generating storyboard + spec: follow `SKILL.md`, `references/spec_format.md`, and use `scenes/gift_city_spec.json` as the worked example. Put the one-line visual brief in the spec root `"look"` string.
