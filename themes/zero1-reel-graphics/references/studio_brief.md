# Graphics Studio (Zero1 reel)

The app renders **1080×1920** PNG/HTML from `spec.frames` only. Ignore zip delivery, Figma limits, and local `render.py` in the skill — the app uses `scripts/build.py` + `templates/render.js`.

When storyboarding:
- One **theme per reel** (A–E in SKILL; never Theme 2 Light Pop).
- Put presenter-only beats in the storyboard text only (`footage`, `screen`, `repeat`).
- Every FSS/OST/anchor graphic needs a frame with `type` `fss`, `html`, `ost`, or `anchor` and enough `html` to preview in studio.
- Copy numbers exactly from script / data sheet.
- Use centred safe-zone layouts; max content width 840px (top band) or 680px (lower band).

Look field: one line naming theme letter + font roles (e.g. "Theme B · Green Grid · Manrope body · serif headlines").
