# Storyboarding move codes (Zero1 Hindi IP)

Tag every beat with 1–3 codes for the moves the team used.

| Code | Move | Example from the real storyboards |
|---|---|---|
| LIT | **Literalise** the VO line into a physical toy-world action or object | "Magar banks se nahi!" → the BANK sign becomes "BANK ?"; "aggressive recovery" → notices stick onto the house one by one; "collapse" → a storm wrecks the board and the building |
| MORPH | An element of the previous frame **transforms** into the next frame's subject | the map outline becomes the bank outline; the 0 of "1,18,000…" turns into binoculars; the year line rises into a demand curve |
| CAM | A **camera move** inside the same world: zoom in/out, pan, tilt up to the sky or down underground, top cam, POV, parallax | "Lekin" → pan down to the crowd → the gate → the under-construction tower; "camera goes underground, water level drops" |
| MATCH | **Match cut**: same position/composition, new place or time | Arjun on the map → the same Arjun, same spot, inside his kirana |
| BUILD | Same set, **one element added or changed** | the house fills red to 83%; a tag field changes; table rows reveal; the checklist ticks |
| NUMOBJ | A **number staged on or with an object** | price-tag banners on the towers; "83%" filling the house; the timeline stops at 2010 + "97 lakh borrowers" |
| TYPO | A **text-led beat** (typo over the scene, pivot word, question) | "LEKIN!", "SALARY ?", "It is simply Normal" |
| GRADE | **Darken / greyscale / sepia** for reveal, focus or the past | the same frame as #18 in sepia = the past; dark night + gold 90% |
| BUBBLE | **Thought bubble** for imagination, memory or doubt | half-opacity stock = imagined; parents in the 1970s inside a bubble; "?" above the head |
| EMO | **Arjun's reaction** carries the beat | scratching his head beside the EMI table; tears and a smile at the wedding |
| DEVICE | A **recurring episode device** | the notebook sticker tag, the timeline spine, the newspaper with flipping pages, the checklist, option boards, see-saw, India map |
| SRC | Source shown as a **physical document** | newspaper headline, article on the wall, paper + rubber stamp |
| DATA | **Data as animated objects** | dots fill, balls merge/roll, pie reveals, table rows reveal |
| CALLBACK | Reuse of an **earlier frame or object** | the conclusion reuses the intro sticker frame; the necklace from Ch-2 at the wedding |
| MONTAGE | **Several mini-scenes at once** | 4 influence scenes around 3 Arjuns; "wear it / preserve / pass on / borrow" collage |
| REGION | **Regional authenticity** requirement | "is chapter ki sari chezein andhra style" |
| UI | Phone / YouTube / website UI | Take Loan button; bonus letter on the phone; YouTube interface |
| SCREEN | Screen capture / real footage, not designed | Zerodha account opening; TV news clips |
| HERO | A **multi-step hero animation**, the episode's showpiece | red balls merge into one big ball and roll the blue ball out of frame; 1920→now generational house |
