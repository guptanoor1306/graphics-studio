### 2. Beat density
- ~86 graphic changes for a ~10–12 min script → roughly **one new frame (or a build-step on the same frame) per VO sentence, often per half-sentence**. Faceless = nothing is ever "hold on talking head".
- Most beats are **builds on a persistent set**, not new sets: same backdrop, add/remove/replace one element (tag text changes, house turns red, sign text changes, dots change colour). New *sets* happen ~every 3–6 beats.
- Reuse is deliberate: #18 ↔ #44/#45 (same composition, then sepia), #30 → #31 → #32 → #33 → #39 (same house), intro → Con#1, #7 map → Con#2.

### 4. Visual system (V1 evidence)
- **Backdrop "Sky-Paper"** (used by ~70% of frames): crumpled white paper texture + soft painted sky/clouds band across top (PSD layers `bg` > `Design` + `Group 15/Texture`, `circle sky shape`). Plain-paper variant (no sky) for timelines & data.
- **Ground:** sandy dirt strip (#DAB08D) for Andhra building frames; village strip for Meghalaya data frames.
- **Characters:** Arjun = tall wooden block head (visible wood grain), two vertical black oval eyes, no mouth/nose, cut-paper black hair fringe (Meghalaya Arjun: red/yellow turban), fabric costume of his state (Andhra: white shirt + angavastram + gold-border dhoti; Kerala: red shirt + mundu; Meghalaya: Khasi black embroidered jacket, red dhoti-pants, bead necklace), blocky hands, grey/silver block shoes. Elders get moustaches; women get hair buns/braids, saree/jainsem.
- **Typography:** Impact (headlines, numbers, years, map labels, signage) + Bricolage Grotesque family (everything else: Light for chapter kicker/labels, Regular for sub-lines, Medium for tag values/placards, SemiBold for article titles, ExtraBold for emphasis values). No other families except inside recreated UIs/articles.
- **Palette:** Red #B23636 (primary accent — alerts, key numbers, emphasis words), Ink #1F1F1F / #000, Tag-brown #592D25, Tag-red #B2372A, Gold #E0A422 / #D7A742 (dark frames, gold topic), Blue #447599 (men / contrast group), Navy sign #083061, Wood map #FAC792, Olive state #A39E66, Ochre flat map #C77F2A, Sand #DAB08D, Paper #F2F2F2.
- **On-screen language:** English, but **Romanised Hinglish phrases are used verbatim from VO** for kickers/questions ("akhir ayi kahan se?", "ab ek aur question hai…", "bullion ya gold ornaments"). No Devanagari.

### 5. Storyboard-doc conventions (how the team writes it)
- Script in Hinglish, black; graphic cue directly under the VO line in green: `#N Graphic - <Hinglish direction>`.
- Decimal cues for inserts (#51.1, #51.2); reused frames say "Use 50 wala graphics" / "same frame as #18".
- Section headers: INTRO, SOP/Reason to Watch, Connector, SECTION n: <State> Money Mindset, CONCLUSION (Con#1…).
- Global designer notes in caps/black ("IMPORTANT NOTE FOR GRAPHIC DESIGNER: … andhra style …").
- `source` hyperlinks placed under the line that needs proof; designer turns them into SRC frames.
- Reference images pasted inline under cues.

### 6. QA issues found in shipped V1 frames (the skill must prevent these)
1. **Typos copied from the script into graphics:** "SELF HELO GROUPS" (#21), "SGHs" (#22/#23), "Sikkam" (#61/#62), "Matrilinieal" (#63). → Skill must spell-check every on-screen string and correct script typos.
2. **Data error on the ID tag:** INFO field shows "₹50 Lakh" (copy of salary) instead of "Same"/"Similar". → Tag fields must be mapped from the VO, not duplicated.
3. **Off-model side characters:** loan officer (#25) and hand/ATM figures (#17–#21) use a smooth Lego/Minecraft-style face, not the wooden-block-with-oval-eyes model. → All humans follow the Arjun character bible.
4. Bank names left as "Bank-1…Bank-4" though the doc asked for accurate 1990s bank names. → Skill must research/fill real names or flag.

### 3. Visual-system confirmations & additions
- Same **Sky-Paper** backdrop (`bg` > `Design` + `Group 15` + `circle sky shape`) in ~60% of frames; ground for Noida = paved plaza / sandy construction dirt.
- **Arjun (single-protagonist version):** same wooden-block head, black cut-paper hair, red tee with pouch pocket, wooden legs, silver shoes. **Expressions are added when the beat needs emotion**: worried = raised brows + down-turned mouth + hand scratching head; happy = smile; aged = moustache + tired brows. Neutral = eyes only.
- **Toy-world vs photo:** toy dioramas for anything with people/action (construction site, office, bathroom, crowd, gate); real-photo cut-outs for real named landmarks and generic luxury towers.
- **Type:** Impact + Bricolage Grotesque again. **Impact has no ₹ glyph** — designers switch to Myriad Pro Bold / RealText / Bricolage for ₹ amounts. Skill rule: set ₹ amounts in Bricolage Grotesque ExtraBold/Bold (or ₹ in Bricolage + digits in Impact). Chapter kicker is "Chapter-N" Bricolage Light 54 (once RealText Italic).
- **Chapter reveal** = Impact 139 two-line title + "Chapter-N" kicker, top-left (or top-centre-left), over a frame from *that chapter's world* (V1: map; V2: towers/skyline/gate). It always reuses or match-cuts from adjacent frames.
- **Colour:** Red #B23636 for the key number/word; gold #E0A422 on dark frames with coloured italic keywords; blue #30749B only for neutral table headers.
- **Hanging-by-string** is a recurring prop language: ID tags (V1), price tags (V2), tables (V2), article cards (V1).

## Patterns confirmed across V1 + V2 (draft rules for the skill)
1. **Structure:** INTRO hook (cold open, character or place) → "Lekin/Magar" pivot → **SOP via "?" shatter** listing the 3–4 questions → numbered **Chapter reveals** (one per section, title = the section's question) → **Connector line** before each chapter → callbacks in CONCLUSION → YouTube end slate. 
2. **Arjun is always the viewer's proxy.** Every abstract money idea is shown as something happening *to Arjun* (his tag, his flat, his phone, his salary).
3. **One beat ≈ one VO sentence or clause.** Default to builds on a persistent set; change set every 3–6 beats; reuse earlier frames for callbacks.
4. **Every number gets a frame**; every source gets a re-typeset SRC/NEWS frame; every list becomes physical objects (placards, checklist, polaroids, tags) — never bullet slides.
5. **Mood switches:** darkened frame + gold type for big reveals/pivots; greyscale world + colour subject for focus; sepia for past.
6. **On-screen text** English (Romanised Hinglish allowed for VO-quoted phrases: "Lekin!", "₹2 cr. ka 75% = ?"). No Devanagari except inside real UIs.
