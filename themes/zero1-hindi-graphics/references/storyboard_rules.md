# Zero1 Hindi IP — storyboard rules

Learned from 3 shipped episodes: *State Culture × Money Mindset* (V1), *The Reality of Noida's Real Estate* (V2), *Kerala's Gold Obsession* (V3). Full beat-by-beat study: `video_breakdowns.md`.

This IP is **faceless: 100% graphics**. No presenter or talking head. Every second of VO sits on a designed frame, and the storyboard *is* the film.

---

## 1. Pick the episode shape first
| Shape | Use when the script… | Chapter logic | Example |
|---|---|---|---|
| **Comparison** | compares several people, places or cases | one chapter per case; each case gets its own Arjun (state costume) | V1: 3 Arjuns, AP / Kerala / Meghalaya |
| **Investigation** | asks whether one decision is worth it (buy / invest / borrow) | chapters = the questions in the SOP, in order | V2: Noida flat; afford? what do you get? is it yours? |
| **Life-story** | follows one person + one object across time | personal bookends (intro + conclusion) around an explainer middle | V3: the daughter's necklace, birth → wedding |

## 2. The fixed spine (every episode)
1. **INTRO hook** (sound-led cold open): "meet ARJUN" / place reveal (map pin → city collage) / the object. Establish Arjun, where he lives, and the money situation within 3–5 beats.
2. **Pivot word.** One giant word frame: *"Lekin!"*, *"But…"*, *"Magar"*. Use a red Impact or italic word, or a darkened frame with a gold word plus a white Bricolage line.
3. **SOP / Reason to Watch.** The 3–4 questions the video answers. Show them as **numbered polaroids** (badge 1. 2. 3.; small Bricolage Light kicker + Impact phrase), optionally arranged around Arjun or around a **"?" made of shards of the previous frames**. The SOP items = the chapter titles, in the same order and the same number. The build warns if they differ.
4. **For each chapter:** connector line (VO) → **chapter reveal** ("Chapter-N" Bricolage Light italic + 2-line Impact title, over that chapter's world: map / skyline / gate / scene) → beats.
5. **CONCLUSION:** call back earlier frames exactly (intro tag frame, map, the object, the family), close on the takeaway typo, then the channel's **end slate** (Arjun with comment / subscribe slates; reuse the channel's existing end animation and mark it `REUSE`).

The connector line must always lead into a chapter reveal. V3 shipped without two reveals ("FIND CONNECTOR"), so never leave that gap. If the script has no connector, write one in Hinglish and flag it.

## 3. Beat density and continuity
- **One graphic change per VO sentence, often per clause.** Build states (`_b`, `_c`) count as changes: a 6-row table revealed row by row is 6 beats on one set. That works out to about 6–9 changes per minute (V1: ~86 beats in ~11 min). Never hold one frame for more than ~10 s of VO.
- Most changes are **builds on a persistent set**: add one element, swap a sign's text, recolour, reveal the next table row, tick the next checklist item. Start a **new set** every 3–6 beats.
- Use **match cuts** between sets: the same Arjun position across a cut (V1 #9→#10), the year line becoming a graph (V2 #4→#5), the map outline becoming a building outline (V1 #41→#42).
- **Callbacks reuse frames exactly** (same composition, then a grade change). Examples: #18 ↔ #44 ↔ #45 sepia in V1, intro ↔ Con#1.
- Number states of one set with suffixes: `1.05`, `1.05_b`, `1.05_c`, each its own PNG.

## 4. Frame vocabulary for each kind of VO line
Use this table **after** `storyboarding_method.md` Pass 3 (literalise → morph/build → camera → …) has decided the move. It tells you which layout carries a given kind of content. A row here never replaces literalising the line in Arjun's world. Codes are in `frame_types.md`; build types are in `spec_format.md`.

| VO is… | Frame | Notes |
|---|---|---|
| Introducing Arjun / a person | CHR on Sky-Paper, or CUTOUT scene (his house) | Kicker "meet" + Impact name |
| Saying where something happens | MAP-W (wooden map + Arjun on state), COLLAGE (city landmarks), DIO (full-bleed place) | Map for states/regions, collage for a city |
| Describing what Arjun does / buys / feels | DIO or CUTOUT scene with Arjun acting | Image gen; expressions only when emotional |
| Stating one number | STAT on/next to the object it describes, with a hand-drawn arrow | Red Impact number + Bricolage label |
| Making a big reveal / turning point | STAT-DK (scene darkened, gold number) or WORD-FX | Max ~3 per episode |
| Comparing two quantities | DATA dots / PICTO / two objects + values / see-saw | Red vs blue groups; never a bar chart slide |
| Comparing 3+ options | OPTION board per option + ✅/❌ lists → HUB with values | V3 Ch-3 |
| Doing arithmetic | CALC (equation → answer swaps in red), or a hung TABLE with rows revealing | Worried Arjun beside |
| Showing a breakdown of costs | EXPLODE (object split into parts with ₹ labels) or TABLE | |
| Showing a list of rules / features | SIGN placards, CHECKLIST clipboard, CALLOUT pills on an aerial, ID TAG fields | Never bullets on a plain slide |
| Citing a study / report / news | SRC article card (re-typeset, highlight the line read), NEWS-WALL, NEWSPAPER spread | Re-typeset, don't screenshot. Show source + date. If you don't have the real sentence, write a close paraphrase and mark it `VERIFY: replace with exact quote + date` in the storyboard |
| Telling history | TL / TL-SPINE: vertical line, red dot, Impact year, a cut-out scene per stop | Timeline moves = new year state |
| Describing a process / chain | FLOW (A → B → C objects with arrows) | |
| Asking a question to the viewer | QMARK shatter, WORD-FX "?" or a red Impact question + Bricolage kicker | |
| Focusing on one thing in a busy world | GREY-FOCUS: world greyscale, subject in colour | |
| Past / memory / tradition | PAST (sepia), MEMORY vignettes (greyscale) | |
| Crisis / risk | red flood / red tint, notices stuck on the house, storm | |
| Plugging another video / product | UI frame (YouTube / phone), SCREEN CAPTURE beat | Mark `SCREEN` |
| Showing a real website / app step | SCREEN CAPTURE (not designed) | Mark `SCREEN` in the storyboard |

## 5. Arjun rules
- Arjun is the viewer's proxy, and every abstract number happens **to him**: his tag, his salary, his flat, his necklace. Put him in or imply him in most frames.
- Use one Arjun per episode unless the shape is *Comparison*. Keep his costume fixed per variant (see `character_and_prompts.md`).
- **Expressions:** neutral = eyes only (default). Worried (brows + down mouth + scratching head) for bad maths. Happy (smile) for resolution. Thinking (hand on chin) for SOP/questions. Aged (grey hair + moustache) for "years later".
- Side characters (family, officials, crowd, guard, jeweller) are **the same wooden-block model**. Never Lego minifigs and never smooth faces. V1, V2 and V3 all shipped off-model side characters, so prevent it.

## 6. On-screen language
- English, but **Romanised Hinglish lifted verbatim from the VO is encouraged** for kickers, questions and pivots: "Lekin!", "₹2 cr. ka 75% = ?", "Iss necklace ka ROI kya hai?", "akhir ayi kahan se?". **Never Devanagari** (except inside a real UI screenshot).
- Write ₹ amounts with **Indian grouping** (₹1,25,466; ₹3,79,11,842) or words (₹1.18 Lakh Crore, ₹2 Crore). Numbers must match the VO exactly.
- **Correct the script's typos; never copy them.** The shipped frames included "SELF HELO", "SGHs", "Sikkam", "Alloted", "Wasteage" and "Matrilinieal".

## 7. Storyboard output format
Use the format in SKILL.md Step 2: a world bible first, then one block per beat in the team's doc layout:
- `#N ~time [set] ← transition`
- `VO:`
- `Cue:` (camera + action, in the team's Hinglish/English voice)
- `Text:`, `Moves:`, `Frames:`, `Make:`

After the beats, add numbers/sources → frames, the plate/asset/gen list, screen captures, rubric scores and flags.
